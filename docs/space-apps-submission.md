## 1. Problem

- Клімат зсувається, звичні культури й сівозміни перестають працювати.
- Дані NASA відкриті, але фермеру вони недоступні за формою: сирі числа, грубі сітки, англомовні портали.
- Малі господарства не мають агронома під рукою.

## 2. Solution

- Сценарій: поле → радіус → історія → (пріоритети) → рекомендація.
- Що показуємо: клімат (клас Кеппена-Гайгера), тип ґрунту (WRB), шість показників агростресу, частки культур, сівозміна на 3 роки, поради з обробітку.
- Чим відрізняємось: пояснення «чому» з числами для кожної поради; чесна впевненість і розбіжність між точками в радіусі; працює глобально, без ключів.

## 3. How it works

- Архітектура: PWA (Vite + React + MapLibre) і API на Cloudflare Workers (Hono), кеш у KV.
- У радіусі беремо до 9 точок, усереднюємо, розбіжність показуємо як невизначеність.
- Логіка рекомендацій правилова і прозора: оцінка культури 0-100 за кліматом, водою, ґрунтом, сівозміною та ризиком.

## 5. Impact

- Хто виграє: малі й середні господарства, агрономи-консультанти, студенти.
- Що змінюється: рішення про сівозміну спирається на дані, а не лише на звичку.
- Обмеження кажемо чесно: клімат це середня норма, а не прогноз; ґрунт це модельна оцінка 250 м, а не аналіз поля; межі орієнтовні; інструмент не замінює агронома.
