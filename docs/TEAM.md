# Команда: хто що робить і як працюємо

## Гілки та папки

| Хто | Гілка | Свої папки | Здає |
| --- | --- | --- | --- |
| Назар (тімлід) | `main` | `shared/`, `docs/`, корінь репо, `wrangler.jsonc` | каркас, контракт, злиття, деплой |
| Сергій | `data` | `data/`, `packages/logic/` | `crops.json`, Кеппен, стрес, `recommend()` |
| Єгор | `backend` | `apps/api/` | Worker: збір даних, кеш, `/api/*` |
| Влад | `ui` | `apps/web/src/` (крім `map/`) | майстер, екран результату, i18n |
| Олексій | `map` | `apps/web/src/map/`, `apps/web/public/`, `docs/demo/` | карта, шари, межі полів, PWA, демо |

## Правила

1. Працюй лише у своїй гілці й у своїх папках. У `main` пушить тільки Назар.
2. `shared/` не чіпай. Потрібне нове поле в контракті: напиши Назару, він додасть у `main`, ти підтягнеш.
3. Не вигадуй числа, URL чи назви шарів. Не впевнений: перевір у документації або реальним запитом, не вийшло: познач `TODO` і скажи.
4. Ключі, токени, паролі в репозиторій не потрапляють (лише `.dev.vars`, він у `.gitignore`).
5. Весь текст для користувача береться з `en.json` / `uk.json` або приходить з API мовою `lang`.
6. Код і коментарі англійською.
7. Перед кожним пушем: `npm run check` (типи, тести, збірка) має проходити.

## Початок роботи

```bash
git clone https://github.com/KrakeNN9336/Space-app.git
cd Space-app
git checkout <твоя гілка>
npm install
npm run dev
```

На Windows клонуй у короткий шлях (наприклад `C:\dev\field-shift`), інакше локальний Worker не стартує.

## Щодня

```bash
git pull origin main
```

Це підтягує свіжий `main` (контракт, каркас) у твою гілку. Роби це зранку і перед здачею.

```bash
npm run check
```

```bash
git add -A && git commit -m "short message" && git push
```

## Що треба пам'ятати про стики

- **Сергій → Єгор.** Єгор викликає `recommend(input: LogicInput): LogicOutput` з `@field-shift/logic`. Сигнатуру не міняти. Опади Єгор передає вже в мм на місяць; PET, Кеппена, сезон і пояснення рахує Сергій.
- **Сергій → Єгор, Влад.** У `data/crops.json` лишається об'єкт із масивом `crops`, у кожної культури є `id`, `name.en`, `name.uk`, `group`, `icon`. Ідентифікатори з насіннєвого файлу (`winter_wheat`, `corn`, `soybean`, `pea`, `clover` ...) не перейменовувати.
- **Єгор → Влад.** Відповідь `/api/analyze` перевіряється командою `npm run test:contract`. Поки бекенд не готовий, Влад працює на `shared/mock-analyze.json`.
- **Олексій → Влад.** `<FieldMap onFieldSelected radiusKm layer />` і `<ClimateCharts data />` експортуються з `apps/web/src/map/`. Влад лише вставляє їх.
- **Залежності.** Нову бібліотеку додавай у свій пакет: `npm install <назва> -w @field-shift/web` (або `api`, `logic`). Через це у `package-lock.json` можливі конфлікти при злитті, це нормально, їх розв'язує Назар.

## Якщо не встигаємо

Відрізаємо в такому порядку: шари NDVI і GRACE, кліматичний шар Кеппена на карті, малювання полігона, пошук полів FTW. Не відрізаємо: точку на карті, радіус, історію, клімат, ґрунт, стрес і рекомендацію.
