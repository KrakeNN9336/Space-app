# Старт для чотирьох учасників

1. **Назар:** бере `data/` і `packages/logic/`, контролює `shared/`, `docs/`, кореневі конфіги, інтегрує PR. Зберігає історію гілки `data`.
2. **Влад:** працює в `ui`, відповідає за історію посівів, результат і просте/наукове пояснення. Не редагує `src/map/`.
3. **Єгор:** працює в `backend`, відповідає за NASA POWER та інші відкриті джерела, API й кеш. Не змінює агрологічні ваги.
4. **Олексій:** працює в `map`, відповідає за карту світу, шари, вибір поля. Не редагує `App.tsx`.

## Перед роботою

```bash
git fetch origin
git checkout <своя-гілка>
git merge origin/main
npm install
npm run check
```

Якщо конфлікт — зупинитися, не робити `git push --force` і не видаляти чужі зміни.

## Контрольні стики

- Влад використовує `FieldMap` з `apps/web/src/map/FieldMap.tsx`; Олексій зберігає `onMapClick(lat, lon, field?)`.
- Єгор повертає `AnalyzeResponse` відповідно до `shared/types.ts`.
- Назар підтримує `recommend(LogicInput)` та `data/crops.json`; зміни контракту обговорюються до реалізації.
- Залежності та lockfile інтегрує Назар.

## Мінімальна демонстрація

Карта → поле або точка → історія трьох років → аналіз → що сіяти/чого уникати → пояснення та джерела.

NASA POWER і NASA GIBS — NASA; FTW/OSM, ISRIC і FAO — інші відкриті джерела. У презентації це називати чесно.
